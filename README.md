# RobotMind Fiber for Home Assistant

Install this repository as a custom HACS integration, then add **RobotMind Fiber**
in Home Assistant. In Fiber UI, open Integrations → Home Assistant, generate a
pairing code, and enter it with the Fiber API URL. The integration opens an
outbound connection; Home Assistant never needs a public inbound port.
